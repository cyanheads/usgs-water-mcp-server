# 0.2.3 — 2026-08-22

## Added

- **MCP protocol support** now serves revision 2026-07-28 alongside 2025-era clients over HTTP.

## Changed

- **Tool contracts** reject undeclared root input keys and advertise the standard error envelope in output schemas.
- **NWIS requests** now carry the request context through framework timeout and retry helpers, preserving cancellation and request correlation across attempts.
- **HTTP deployment** explicitly uses stateless sessions in `.env.example` and Docker. Choosing `auto` still resolves to stateful sessions.
- **Project tooling** now uses Bun 1.4, TypeScript 7, split source/test typechecking, portable MCPB cleanup, and the current framework skills and checks.
- **Security reports** now use `security@caseyjhand.com`.
