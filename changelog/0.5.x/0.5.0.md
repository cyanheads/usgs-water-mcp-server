# 0.5.0 — 2026-10-28

## Added

- **`usgs-water-guide` skill** in `skills/`, served over MCP as `skill://usgs-water-guide/SKILL.md` (with the `skill://{+path}` template) through `createApp({ skills: 'skills' })` from mcp-ts-core 0.13.18, and shipped in the npm package, Docker image, `.mcpb` bundle, and plugin installs. It covers telling live gages from dormant ones, the two-hour window of `water_get_conditions`, inverted depth-to-water (72019) rankings, choosing a site's parameter code, time zones and data lag, and casting the text columns of a staged series in SQL. The server `instructions` point to it.

## Changed

- **`water_get_series` and `water_find_sites` notices** are set through `ctx.enrich.notice()`. mcp-ts-core 0.13.18 renders generic enrichment string values as code spans, so a notice set through the generic slot would lose its blockquote; through `ctx.enrich.notice()` it stays a quoted `> ` line in `content[]`, and `structuredContent.notice` stays the raw string.
- **Tool error text** (`Error:`, `Recovery:`, `reason`) in `content[]` is Markdown-escaped while `structuredContent` is unchanged; an oversized-bbox error renders `\[7.0x5.0 degrees\]` in `content[]` (mcp-ts-core 0.13.16).
- **Cancelled calls**: a handler that returns after its request was cancelled settles as `RequestCancelled` (`-32011`) instead of a success (mcp-ts-core 0.13.16).
- **Startup** stops and names the variable when a framework env value is out of range: fractional or negative counts, timers outside `setTimeout` range (mcp-ts-core 0.13.16).
- **HTTP transport** answers `503` with `Retry-After` while shutting down, and CORS exposes `WWW-Authenticate` and `Retry-After` (mcp-ts-core 0.13.16).
- **Packaging**: root Agent Plugins 1.0.0 `plugin.json` and `mcp.json` (mcp-ts-core 0.13.18 template); `.mcpbignore` moves to the root-anchored template set; `skills/` ships in the npm package `files` and the Docker image; the `.mcpb` keeps the MCP SDK's runtime `dist/ext/skills/` modules while dropping node-gyp build output and the framework's build-only files (cleaner and packaging-lint fix tracked upstream as cyanheads/mcp-ts-core#794).
- **README** getting-started section and the bug-report issue template are shortened to the current templates; development skills and scripts are resynced with the framework.
